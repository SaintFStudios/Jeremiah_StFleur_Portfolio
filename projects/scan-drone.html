Mar 2025 – Mar 2025 Robotics & Controls
Robotics ESP32 PID Control BLE Custom PCB
// Overview

Inspired by Rainbow Six Siege, this 3D-printed terrestrial drone was crafted to test the capabilities of the RemoteXY library with BLE control. It uses continuous servos and time-of-flight sensor for navigation and motion, TPU wheels for extra traction, and and a tiny RGB light for visual feedback.

// Firmware

REMOTE_XY_SLIDER_AND_DIST_SENSOR.ino

Full BLE control firmware — dual slider input maps to continuous servo angles, with live VL53L0X distance fed back to the app

REMOTE_XY_SLIDER_AND_DIST_SENSOR.ino C++ / Arduino
// RemoteXY — BLE connection mode
#define REMOTEXY_MODE__ESP32CORE_BLUETOOTH
#define REMOTEXY_BLUETOOTH_NAME "R6 Drone"
#include <RemoteXY.h>
#include <ESP32Servo.h>
#include <VL53L0X.h>
 
// GUI struct — auto-generated by RemoteXY editor
struct {
  int8_t  Left_Motor;   // slider: -100 to 100
  int8_t  Right_Motor;  // slider: -100 to 100
  float   value_01;     // distance sensor out
  uint8_t connect_flag;
} RemoteXY;
 
void setup() {
  RemoteXY_Init();
  leftServo.attach(leftServoPin, 1000, 2000);
  rightServo.attach(rightServoPin, 1000, 2000);
}
 
void loop() {
  RemoteXY_Handler();
  // read distance sensor → send to app
  int sensorValue = analogRead(distanceSensorPin);
  RemoteXY.value_01 = sensorValue;
 
  // map slider → servo angle
  int leftAngle = map(RemoteXY.Left_Motor, -100, 100, 0, 180);
  int rightAngle = map(RemoteXY.Right_Motor, 100, -100, 0, 180);
 
  leftServo.write(leftAngle);
  rightServo.write(rightAngle);
  delay(20);
}
